## Missed by the lane

1. **A built-in needs-you signal already exists.** The session registry `status:"waiting"`, together with `waitingFor`/`needs`, plus the `claude agents` view's "Needs input" column and its `N needs you · N working · N idle` counts, overlaps nebi-constellation and partly overlaps the beacon files (B@197235449, B@197309909, B@209238115). In bypass mode it fires on AskUserQuestion, elicitation and other dialogs, but not on prose questions.
2. **Marketplace plugin notices.** "Plugins changed. Run /reload-plugins to activate." and "Plugin(s) updated: …" appear for marketplace installs. These are clutter candidates the lane attributed to dev-mod sessions (B@208206058, B@209543657).
3. **The browser routing has more conditions.** The attacher's BROWSER overrides the session's env. Remote-control clients skip auto-open. `CLAUDE_CODE_ARTIFACT_AUTO_OPEN=0` also blocks the explicit Artifact `open` action. BROWSER also governs clicked transcript links (B@193116597, B@210297844, B@193344035).
4. **Another mods gate.** The rollout gate also requires a non-diskless session (B@179061388). Policy and user `disableAllHooks` plus `allowManagedHooksOnly` gate installed mods through `nwn` (B@182892757, B@182893126).
5. **The mods are not in git.** `git status --short mods` prints `?? mods/`. Only ~/.claude/plugins/cache holds copies, so they are one bad edit away from loss.
6. **More fleet-radar writes.** fleet-radar also writes the `now` atom every second while the ticker runs (register.tsx:139). Each write redraws whatever reads `now`.
