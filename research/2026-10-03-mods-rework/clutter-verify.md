## Missed by the lane

1. The engine already treats ambient artifact watchers as background noise, not real work. `m8e()` excludes `monitor_ws` with `ambient:true` from monitor counts, and `xt()` flags it as non-explicit ambient (@184858227). Only `Gqt()`, the Stop-hook payload, leaks them. This is an upstream bug worth a /feedback report alongside the local filter.
2. Each published artifact can add **two** never-ending tasks: live updates plus presence. That explains nudges reading "2/3/4… background tasks". Older watchers idle-expire, but the newest publish and explicit watches never do.
3. The everyday footer already hides "(shift+tab to cycle)" whenever a background-task pill shows (`ur` counts it).
4. Live copies match the repo: beacon 0.2.1, constellation and model-lock show 0 diffs, and the deployed statusline and output style are identical. Line references hold for what actually runs.
5. Theme: Ghostty switches light and dark automatically, and Claude is pinned to `dark`. `auto` is a valid value and probably fixes contrast in the light terminal.
